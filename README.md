

🐼 Interactive Panda Login Form (Tailwind)

An animated and interactive Login Form built with HTML, Tailwind CSS, and Vanilla JavaScript.

This project features a cute panda character that reacts to user actions in real-time — making the login experience playful and fun.

📸 Preview

(https://zahra-azizi-dev.github.io/loginform/)

✨ Features

🐼 Animated panda character (face, eyes, blush, hands)

👀 Eyes move while typing in the username field

🙈 Panda covers its eyes when the password input is focused

🖱️ Custom panda cursor that follows mouse movement

😴 Panda blinks on mouse click (mousedown / mouseup)

🎨 Clean UI styled with Tailwind CSS utility classes

⚡ Smooth animations using CSS transitions & transforms

🧠 DOM manipulation and event handling with Vanilla JS

🧠 How It Works

Username typing triggers eye movement based on input length.

Password focus rotates/translates the panda hands to cover the eyes.

A custom panda cursor follows the mouse using the mousemove event.

On mouse down, panda eyelids scale down to simulate blinking.

Tailwind classes handle layout, spacing, colors, and responsiveness.

🛠️ Technologies Used

HTML5

Tailwind CSS

Vanilla JavaScript (DOM & Events)

Font Awesome (icons)
